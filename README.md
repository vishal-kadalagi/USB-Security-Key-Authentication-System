# 🔐 USB Security Key Application

**Academic Year:** 2022–23  

This project is a Tkinter-based Python application that provides a USB Security Key system. It includes user signup/login, USB detection, email-based OTP key generation, and secure directory access using a decryption key.

---

## 📌 Features
- 🔍 USB drive detection using system commands  
- 👤 Signup and Login system connected to MySQL  
- 🔑 Email OTP-based security key generation  
- 🗂 Directory viewer with decryption key verification  
- 🪟 Multi-window GUI (Home, About, Guide, Signup, Login, USB Check, Key Generation, Directory Access)  
- 🎞 Video and image support using MoviePy, OpenCV, and PIL  

---

## 🛠 Technologies Used
- Python  
- Tkinter  
- PIL  
- MoviePy  
- OpenCV  
- MySQL Database (mysql-connector)  
- SMTP Email (for OTP delivery)  
- OS & Subprocess (USB detection)  

---

## ▶️ How to Run
python main.py

---

# 🔄 Project Flow

1. USB is checked on startup  
2. Home page opens  
3. User can Signup or Login  
4. Admin can generate OTP-based security key  
5. USB drive is verified  
6. User accesses selected directory after entering the correct decryption key
